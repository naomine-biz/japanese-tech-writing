# japanese-tech-writing

日本語の技術文書・書籍原稿の執筆と、技術説明の推敲に使うスキル。
主張・仕組み・成立条件がつながる本文を作り、技術的に整えた原稿を読みやすさの推敲へ渡す。

## この派生版での変更

- 執筆と技術説明の推敲が担う入力・作業・成果物を明確にした。
- 主張・仕組み・成立条件から説明を組み立てる規範にした。
- 想像上の誤解への反論や、否定・留保の反復を、節と段落を通して見直す。
- 技術的な制約、反例、検証範囲、否定が表す論理を保つ。
- 説明の不足を執筆工程で補い、読みやすさの推敲へ渡す前に確認する。
